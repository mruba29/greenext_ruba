Largest Contentful Paint (LCP) - **Desktop (1.29s — PASS):** The desktop browser rapidly renders the hero section. Total Blocking Time (TBT) - **Desktop (46ms — PASS):** Desktop CPU cores execute the client-side JavaScript bundle (`main.js`, `nav.js`, `analytics.js`) in under 50ms, leaving the main thread unblocked. - **Mobile (393ms — WARNING):** On 4x throttled mobile CPUs, parsing and executing bundled scripts creates tasks exceeding the 50ms threshold. - **Prescription:** Defer non-critical analytics flushes and dynamically import the AI assistant chat widget only when toggled. #### 3. Cumulative Layout Shift (CLS) - **Desktop (0.001 — PASS) & Mobile (0.000 — PASS):** GreenNext achieves exceptional visual stability. All image containers, hero banners, and grid cards possess predefined aspect ratios and CSS min-height rules, preventing layout jumps during resource loading. --- ## 3.
